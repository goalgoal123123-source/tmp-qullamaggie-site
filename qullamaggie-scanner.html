● 咩係 Qullamaggie 方法論？

Kristjan Kullamägi（網名 Qullamaggie）係近年最受關注嘅動量交易員之一，以捕捉股票「突破」——股價喺沉寂一段時間後突然向上爆發——見稱。佢嘅方法唔係靠內幕，而係靠一套可重複嘅 checklist：

🌊

順勢而為

只喺大市健康嗰陣出手；大市轉弱嗰陣，好圖表都會失敗。掃描器用 5 個大市闊度指標將市況分為有利／混雜／謹慎／避險四級。

⚡

催化劑先行

突破之前通常有「原因」——成交量突然放大 3 倍以上，代表有資金入場。掃描器會偵測呢啲日子，再計催化劑有幾「新鮮」。

🌀

整固如彈簧

大升之後嘅橫行整固越窄、越乾淨，下一次突破越爆。掃描器量度區間闊窄、K 線質素、均線排列。

💪

相對強度

大市橫行但隻股靜靜雞升，代表背後有需求。掃描器將每隻股嘅強度同成個股票池＋SPY＋行業 ETF 比較。

💡 設計哲學：掃描器只負責整理功課——畀原始數值，唔畀綜合評分，唔畀買賣訊號。決定永遠係你自己做。

● 六大因子類別 （撳入睇詳情）

每隻股票都會經過以下六組因子分析，結果直接顯示喺儀表板卡片上，用顏色標示質素。

● 運作流程

由數據抓取到交易訊號，一條完整流水線，全部喺你部機本地運行。

1

股票池建立

由 SEC EDGAR 拎齊 NYSE＋NASDAQ 所有 ticker，過濾到 $5 以上、20 日平均成交量 50 萬股以上，剩低約 2,300 隻夠流動性嘅股。

2

下載行情數據

經 yfinance（Yahoo Finance，免費）分批下載一年日線 OHLCV；Parquet 本地快取，16 小時先更新一次，快取命中時成個掃描只係約 12 秒。

3

大市把關

先計大市處境：闊度指標、VIX、突破跟進率。若判定為 Risk Off（避險），直接壓制輸出——唔畀你喺壞市況亂嚟。

4

六因子分析

每隻股計催化劑、成交量、整固、相對強度、突破位、週線共振六組數值。

5

四層排序

按實證排序：多因子組合質素 → 高低點結構（HH/HL）→ ATR 收縮 → 突破位距離，排出一張 watchlist。

6

輸出儀表板＋訊號

生成單文件深色 HTML（離線都開到）＋ JSON；同時寫出交易訊號（入場／止蝕／倉位，1% 風險 sizing）畀紙交易模擬器用。

● 使用指南

開源 MIT 授權，任何人都可以免費下載使用。以下係基本安裝同常用模式。

快速開始

git clone https://github.com/VladPetrariu/Qullamaggie-breakout-scanner.git
cd Qullamaggie-breakout-scanner
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m scanner   # 跑完自動開 scans/scan_YYYY-MM-DD.html
指令用途
python -m scanner --watch盤中監控：輪詢報價，接近突破位時 macOS 通知
python -m scanner --backtestWalk-forward 回測：驗證排名喺歷史數據嘅表現
python -m scanner --signals打印今日可執行訊號（入場／止蝕／倉位大小）
python -m scanner --paper紙交易模擬：用真實翌日數據計 P&L，唔使券商戶口
python -m scanner --paper-report完整紙戶口報告：統計、訊號漏斗、go-live 門檻
python -m scanner --no-open唔自動開瀏覽器（畀 cron／launchd 定時用）

每日自動運行（macOS）

./scripts/install_automation.sh   # launchd：逢交易日朝早 5:45 自動掃描＋紙模擬

● 常見問題

要唔要畀錢／申請 API key？
唔使。數據來自 SEC EDGAR（公開）同 yfinance（Yahoo Finance 免費接口），成個項目零成本運行。
第一次跑要幾耐？
第一次要下載 7,000+ 隻股一年日線數據，大約 4 分鐘。之後靠本地 Parquet 快取（16 小時 TTL），一般約 12 秒完成。
掃描器會唔會直接叫我買／賣？
唔會。佢只輸出原始因子數值同排名，唔做綜合評分、唔畀買賣訊號。交易決定永遠係你自己嘅責任。
支援港股／A股嗎？
原生設計係 NYSE＋NASDAQ 美股。源碼開源（MIT），有 Python 能力嘅可以自己改 universe.py 同數據源去支援其他市場。
部機要長開嗎？
唔使。macOS 可用 launchd 設逢交易日 5:45 自動跑；就算部機瞓著咗，下次醒來會補跑，紙模擬冪等唔會重複計。
呢個網站同原項目咩關係？
呢個係介紹網站，方便手機／分享瀏覽；真正嘅掃描器要喺電腦裝 Python 跑。源碼同授權歸原作者 VladPetrariu（MIT License），方法論歸 Kristjan Kullamägi。
